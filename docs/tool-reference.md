# Tool Reference

Ledgerhall (uk-business-mcp) mounts four upstream servers and re-exports their tools under a prefix. Each upstream's own reference has the detail.

The tables are generated by `scripts/gen_reference.py` from `fastmcp inspect`, which lists the live upstreams' tools; edit the prose, not the tables. Regenerate after any upstream release that changes its surface.
